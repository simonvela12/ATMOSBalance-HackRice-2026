# Finanzas2026 iOS app

An early SwiftUI prototype for a weather-themed personal finance app.

## Open in Xcode

1. Install the latest Xcode from the Mac App Store.
2. Open `Finanzas2026.xcodeproj`.
3. Select the `Finanzas2026` scheme and an iPhone simulator.
4. Press Run.

The temporary bundle identifier is `com.hackathon.finanzas2026`. Select a development team under **Signing & Capabilities** before running on a physical iPhone.
